# De Competente Toekomst

Een open boek over competentie, keuzevrijheid en toekomstgericht denken — geschreven door Karel en gepubliceerd via GitHub Pages.

## Over dit boek

Dit boek verkent wat het betekent om competent te zijn in een wereld die steeds complexer wordt. Het behandelt onderwerpen als persoonlijke groei, besluitvorming, ethiek en de rol van technologie in ons dagelijks leven. De inhoud is bedoeld voor iedereen die bewuster wil omgaan met keuzes, verantwoordelijkheid en de toekomst.

**Doel:** een toegankelijk, open-source naslagwerk dat lezers helpt om eigenzinnig, competent en toekomstgericht te denken en handelen.

**Taal:** Nederlands (met Engelse vertalingen in voorbereiding).

**Status:** actief in ontwikkeling — nieuwe hoofdstukken worden regelmatig toegevoegd.

Het boek is opgebouwd uit hoofdstukken, elk met een eigen focus op competentie en toekomstdenken. De inhoud wordt gegenereerd vanuit `src/data/book.json` en gepubliceerd via GitHub Actions.
